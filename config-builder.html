Gumawa ng server config

Parehong fields ng Custom Config screen ng Babayaga VPN app. Pag ni-save, direktang na-a-update ang config.html mo sa GitHub — kukunin ito ng app sa susunod na pindot ng "Fetch" icon (katabi ng bell) sa Servers screen.

1. GitHub repo

Hindi na-save/na-transmit ang token mo kahit saan liban sa GitHub API. Kung gusto mong hindi na mag-paste ulit: ilagay ang Token at isang passphrase, tapos pindutin ang "I-save ang token" — mae-encrypt ito (AES-GCM, derived mula sa passphrase mo) at mase-save lang sa browser na ito (localStorage), hindi sa GitHub o sa config.html. Sa susunod na bisita mo dito, ilagay lang ang passphrase at pindutin ang Enter o "I-unlock ang token" para awtomatikong mapunan ang Token field. Gumamit ng malakas na passphrase, at huwag i-save ang token sa shared/public na computer — may "Kalimutan" button para tanggalin ang naka-save anumang oras. Kung ayaw mo ng feature na ito, gumagana pa rin nang normal ang builder gaya ng dati — ikaw lang mismo ang maglalagay ng token tuwing gagamit.

Export / Import (para sa ibang browser o device)

Ito ang ligtas na paraan para dalhin ang token mo sa ibang browser o device — hindi ito naka-save sa config.html o sa GitHub, kaya hindi ito nakikita ng app o ng kahit sino may access sa repo mo. Gamitin ang parehong passphrase (sa Passphrase field sa itaas) pareho sa Export at Import. Ang blob mismo ay walang silbi nang wala ang tamang passphrase — pero ikaw pa rin ang bahalang mag-ingat kung saan mo ito ipapadala (hal. sarili mong Notes/private message lang, hindi sa public na lugar).
