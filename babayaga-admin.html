BABAYAGA Admin

Dito mo ilalagay ang mga VPS login. Na-e-encrypt ito at nase-save sa GitHub, tapos kusa itong kukunin ng panel.

GitHub

GitHub token: gumawa ng fine-grained token para sa repo na ito lang, Contents: Read and write. Ang passphrase ay ilalagay mo rin sa panel nang isang beses sa bawat device. Gumamit ng 12+ na character.

Mga VPS

Ang una sa listahan ang master. Dito unang kokonekta ang panel, at ang master na ang kokonekta sa iba.

Export / Import

Ang plain export ay hindi naka-encrypt. Nakikita doon ang lahat ng token, kaya itago mo ito at wag i-upload kahit saan.
